# Functions unreachable from the production `main` packages, frozen 2026-08-30.
#
# WHY THIS FILE EXISTS. `golangci-lint` runs with defaults and its `unused` check
# does NOT report EXPORTED identifiers -- it assumes another package may call
# them. So an exported function whose only caller was deleted stays green
# forever. Measured: `RecordClaimLeafStats` was written 2026-04-20, its only
# caller went away with claim_pipeline.go on 2026-06-24, and for four months the
# linter, CI and the repo's own metric check all passed while
# docs/CLAIM_LEAF_MODEL.md told operators to watch a counter that could not move.
#
# A TEST IS NOT A CALLER. `deadcode` runs with the production mains as roots and
# test files excluded, on purpose: a function kept alive only by its own unit
# test is exactly the self-deception this gate exists to catch.
#
# HOW TO USE IT. Every line is one function that is knowingly unreachable, with
# the reason. Adding a line is a decision, not a formality -- if you cannot write
# the reason, the answer is to delete the function or wire it up. A function that
# appears in the scan and NOT here fails the gate.
#
# STATUS: these 27 are the frozen backlog, triaged in
# scripts/localonly/TRIAGE-deadcode-28.md. They are NOT approved to stay -- most
# are queued for deletion. They are listed so the count cannot grow while that
# is decided.
